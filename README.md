# 📖 Qualisp Book

**Ориентировочная книга по языку программирования Qualisp** (ранее QLISP) — Лиспу для машинного обучения и AI.

Qualisp — диалект Лиспа, интерпретатор и JIT-компилятор которого работают прямо на S-выражениях (copy-and-patch в нативные страницы без промежуточного IR), со встроенной тензорной системой (F16/F32/F64/I32/I64/U8), автоградиентом, стенсил-компиляцией HLO-кёрнелов и нейросимвольным слоем (rule engine, унификация, `NS-IF`/`NS-GRAD!` с guilt detector) — всё в стандартной библиотеке, без единого `pip install`.

Свойства, которые отличают Qualisp от обычного ML-стека:

- **Память без GC и без арен.** Модель HibLin: три пула (exact-size пул тензорных буферов, пул cons-ячеек, stable-память для долгоживущих структур), структурные данные живут под подсчётом ссылок, тензорные — с одним владельцем и точным размером. Ни пауз GC, ни перерасхода памяти.
- **Инвариант одной формы.** S-выражение — единственное представление программы. Нативный код (JIT-замыкания и HLO-кёрнелы) — выбрасываемый кэш, выведенный из S-выражений; у HLO мастер-копия программы — форма графа, а понижение — одноразовый кэш.
- **Гомоиконность в рантайме.** `EVAL`, `READ-FROM-STRING`, `WRITE-TO-STRING`, `FUNCTION-BODY`, `SYMBOL-NAME` — код доступен как данные.
- **ML — часть языка.** Тензоры, лента градиентов, оптимизаторы, классические алгоритмы ML, аудио, строковые утилиты, табличный модуль Tablet, нейросимвольный движок — 13 вшитых модулей, один бинарник ~2 МБ.
- **Многослойный ML-путь.** Интерпретатор, SIMD-ядра (AVX2/NEON), OpenBLAS для матриц, HLO-стенсилы на W^X-страницах — без LLVM в рантайме.
- **Диагностика вместо тишины.** Неверная арность, выход за границы, нечисловые веса, потерянный градиент — всё это даёт названную ошибку или предупреждение, а не мусор в результате.
- **Полноценный LSP-сервер** (`qualisp-lsp`): определения, ссылки, hover, автодополнения, folding, форматирование.

Книга написана для **инженеров с Python-бэкграундом**: каждая глава содержит аналогии с Python, NumPy, PyTorch и scikit-learn.

## Быстрый старт

```bash
# Скачать бинарник (Linux x86_64, релиз v2.9.0)
curl -L https://github.com/FQingLars/Qualisp-Project/releases/download/v2.9.0/qualisp-linux-x86_64 -o qualisp
chmod +x qualisp && mv qualisp ~/.local/bin/

# Windows: qualisp-windows-x86_64.zip со страницы релизов (qualisp.exe, qualisp-lsp.exe, qvalent.exe)

# REPL
qualisp
```

## Для кого эта книга

- **ML-инженеры на Python**, которым нужен компилируемый язык без GIL, без GC-пауз и с нативной производительностью.
- **Лисперы**, которым нужен современный инструментарий ML: тензоры, автоград, HLO-компиляция, нейросимвольный движок.
- **Исследователи нейросимвольного AI**: Qualisp сочетает гомоиконный символьный движок (правила, унификация, паттерн-матчинг, `NS-IF`/`NS-GRAD!` с guilt detector) с нейросетевым бэктендом (автоград, HLO, SIMD).

## Что описывает книга

Книга синхронизирована с **Qualisp 2.9.0** и описывает язык в его нынешнем виде — без истории изменений: устройство и контракты, а не список релизов.

- **Модель памяти и владение** — пулы, scope, подсчёт ссылок для структурных данных, exact-size пул для тензоров, `(mem-report)`, проверочные гейты — гл. 5.
- **Язык** — S-выражения, функции, макросы, гомоиконность, типизация, честные ошибки арности и границ — гл. 3, 4, 12.
- **ML-подсистемы** — тензоры, лента градиентов, шаги оптимизаторов, модуль DL, классический ML, модуль Tablet — гл. 6–9, 22.
- **Компиляция** — форма HLO-графа как мастер-программа, проходы на форме, стенсильный эмиттер copy-and-patch, JIT замыканий, образы мира — гл. 10, 20, 21.
- **Символьный слой** — rule engine, унификация, бэктрекинг, нейросимвольная маршрутизация и движок blackit — гл. 14.
- **Инструменты** — стандартная библиотека, пакетный менеджер, FFI, LSP, гейты качества — гл. 11, 15, 16, 19.

Известные ограничения (подробности — в соответствующих главах):

- **GPU-бэкенда нет**: устройство одно — CPU; CUDA/ROCm-кода в проекте нет, интерфейс `Device` оставлен на будущее.
- **HLO**: в нативный стенсиль попадают только F32 и I32 — f16 идёт в интерпретаторный фоллбэк; часть буферов узлов при ROUTE освобождается небезопасно; `ABS` на тензоре отдаёт мусор; `codegen_kind` остаётся единственным местом, где тело ядра не хранится как S-выражение.
- **`let` под биндингом с 1- или 2-байтным dtype** теряет свои биндинги (обход — `defvar`).
- **Подсчёт ссылок для scratch-ячеек** доведён до счётчика, но полноценное владение ими на границе переписывания интерпретатора — в работе.
- **Сравнение плавающих в release-сборке ненадёжно** (`-ffast-math`): конечность проверяется примитивом `(FINITE? t)`, числовые пороги в тестах ставятся выше baseline вырожденного решения.
- **Глубокая не-хвостовая рекурсия** переполняет стек; self-хвостовой вызов оптимизируется и глубину не наращивает.
- **Острова циклов** (ячейка ссылается на саму себя) не собираются: GC в языке нет.
